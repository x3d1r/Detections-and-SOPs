### 2. DETECTION OVERVIEW

**Description:**

This detection is built to identify unauthorized local account creation on endpoints. It is designed to catch potential adversary behaviour where accounts are created for persistence or lateral movement. 

**Hypothesis:**

We hypothesize that an adversary performing unauthorized local user account creation will execute this activity using tools or scripts that bypass standard administrative processes. This activity can be observed through specific event logs and account creation patterns.

**MITRE ATT&CK® Mapping:**

- **Tactic(s):** Credential Access (TA0006), Persistence (TA0003)
- **Technique(s):** OS Credential Dumping (T1003), Account Manipulation (T1098)
- **Sub-technique(s):** LSASS Memory (T1003.001), Local Account Creation (T1098.003)

### 4. LOGIC & IMPLEMENTATION

**Detection Logic (Pseudocode or SIEM Query):**

-- Provide the query here.  
-- Comment heavily to explain each logical step of the query.

```
let SafeAccounts = dynamic(["lenovo", "s-", "thirtydays"]); //, "s-", "reportserveruser", "cliusr", "defaultuser0", "gblocaladmin", "oracle", "intunetest", "kioskuser", "temp", "clitest2", "localadmin", "imageright", "fffff"]);
let SafeInitAccounts = dynamic(["intunetest", "a-", "s-", "cdl_"]);
let AllDomainControllers =
        DeviceNetworkEvents
        | where Timestamp > ago(30d)
        | where LocalPort == 88
        | where LocalIPType == "FourToSixMapping"
        //| extend DCDevicename = tostring(split(DeviceName,".")[0])
        | extend DCDevicename = DeviceName
        | distinct DCDevicename;
// COM003 – Local User creation 
let LapsAccounts = dynamic (["locadm","pcadm"]);
DeviceEvents
| where ActionType == "UserAccountCreated" 
| where AccountName !in (LapsAccounts)
| where not(AccountName has_any (SafeAccounts))
| where not(InitiatingProcessAccountName has_any (SafeInitAccounts))
| where DeviceName !in (AllDomainControllers)
| where AccountName != "defaultuser0" and AccountName !contains "user" 
| where not(InitiatingProcessAccountName contains replace(@"$", "", AccountDomain)) // this filter out all the AccountDomain == to the InitiatingProcessAccountName so we dont see a bunch of alerts 
```

**Known False Positives:**

- Filtering out a lot of the noise by removing any results that may regard legitimate activity include querying out defaultuser0, a- accounts, lenovo, s-, cdl\_ and thirtydays accounts.
- IT staff may use this to create accounts for testing or maintenence
- automated account creation by authorised scripts or tools may also have an impact on FP rate

**Exclusion Strategy:**

- Filter out accounts matching known safe patterns (e.g., "lenovo", "s-", "thirtydays").
- Exclude accounts created by processes initiated by trusted accounts (e.g., "intunetest", "a-", "cdl\_").
- Exclude activity on domain controllers.
