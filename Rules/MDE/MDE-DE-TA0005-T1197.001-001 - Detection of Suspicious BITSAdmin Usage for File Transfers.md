### **2. DETECTION OVERVIEW**

**Description:**

This detection identifies suspicious usage of \`bitsadmin.exe\` with `/create", "/addfile", "/setnotifycmdline", "/resume", "/transfer"`\` parameters, which is often abused by attackers to download or upload malicious files. The detection focuses on instances where \`bitsadmin.exe\` is executed by terminal processes like \`cmd.exe\` or \`powershell.exe\`. This behaviour is indicative of potential misuse of the Background Intelligent Transfer Service (BITS) for malicious activities.

**Hypothesis:**

We hypothesise that an adversary performing file transfer operations (MITRE ATT&CK Technique T1105 - Ingress Tool Transfer) or abusing BITS jobs (T1197 - BITS Jobs) will execute \`bitsadmin.exe\` with specific parameters such as \`/transfer\`. This activity can be observed through process creation events, command-line arguments, and initiating processes.

### **4. LOGIC & IMPLEMENTATION**

**Detection Logic (Pseudocode or SIEM Query):**


```
// AlertEvidence
// BITS Jobs
    //   - ' /create '
    //   - ' /addfile '
    //   - ' /setnotifycmdline '
    //   - ' /resume '
    //   - ' /transfer '
// Techniques: Defense Evasion, Persistence
// ID: T1197
let BitsTransfer = dynamic(["/create","/addfile", "/setnotifycmdline", "/resume", "/transfer" ]);
let WinTerminals = dynamic(["cmd.exe", "powershell.exe"]);
DeviceProcessEvents
| where ProcessVersionInfoOriginalFileName == @"bitsadmin.exe"
| where InitiatingProcessFileName in (WinTerminals)
| where ProcessCommandLine has_any (BitsTransfer)
| project-keep Timestamp, ReportId, DeviceId, DeviceName, ActionType, FileName, InitiatingProcessFileName, ProcessCommandLine, AccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath  
```

**Known False Positives:**

- Legitimate administrative use of bitsadmin.exe for file transfers or updates.

**Exclusion Strategy:**

Ensure these bitsadmin.exe only partain particular command line parameters
