### **2. DETECTION OVERVIEW**

**Description:**

This detection detects activity where conhost.exe is launched by explorer with base64-encoded strings in its command line. Such behaviour is indicative of obfuscated PowerShell commands, often used by adversaries to execute malicious payloads while evading detection.

**Hypothesis:**

We hypothesis that adversaries may leverage Powershell commands will encode payloads in base64 and execute via conhost.exe. This activity can be observed through the presence of base64 strings in the ProcessCommandLine field.

### **4. LOGIC & IMPLEMENTATION**

**Detection Logic (Pseudocode or SIEM Query):**

-- Provide the query here.  
-- Comment heavily to explain each logical step of the query.

```
DeviceProcessEvents // obfuscation through base64 powershell and decoder - observing connections from conhost to suspicious URL's
| where InitiatingProcessFileName == "explorer.exe" // looking for process intitiated from explorer
| where FileName contains "conhost.exe" // conhost spawn
| extend SplitLaunchString = split(ProcessCommandLine, " ") //SplitLaunchString aids in cleaning the regex search
| mv-expand SplitLaunchString
| where SplitLaunchString matches regex "^[A-Za-z0-9+/]{50,}[=]{0,2}$" //regex pattern to pick up on base64 patterns
| extend Base64 = tostring(SplitLaunchString)
| extend DecodedString = base64_decode_tostring(Base64) // decoder
| where isnotempty(DecodedString)
| where AccountName !in ("system") // not system executed
| project Timestamp, DeviceId, DeviceName, ActionType, FileName, FolderPath, ProcessCommandLine, DecodedString, AccountName, AccountUpn, InitiatingProcessAccountUpn
```
