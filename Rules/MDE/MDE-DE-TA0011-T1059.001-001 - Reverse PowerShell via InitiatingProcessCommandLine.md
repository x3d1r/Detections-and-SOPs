### 2. DETECTION OVERVIEW

**Description:**

This detection identifies potential malicious PowerShell reverse shell commands executed on endpoints. Reverse shells to gain remote access to compromised systems, this detection is focused on identifying specific patterns in PowerShell Command lines that are indicative of reverse shell activity.

**Hypothesis:**

We hypothesise that an adversary performing Command and Control (C2) activities using PowerShell reverse shells and will execute specific command line patterns.

**MITRE ATT&CK® Mapping:**

- **Tactic(s):** Command and Control (TA0011)
- **Technique(s):** Command and Scripting Interpreter (T1059)

### 4. LOGIC & IMPLEMENTATION

**Detection Logic (Pseudocode or SIEM Query):**

```
// Cases work to have a list of commands with attatched cases to them, this can aide in listing out multiple reverse powershell commands and put them in to one detection instead of having multiple across the environment   
DeviceProcessEvents
| where InitiatingProcessCommandLine has "powershell"
| extend DetectedScript = case(
    InitiatingProcessCommandLine has "data 2>&1 | Out-String", "Script2",
    InitiatingProcessCommandLine has "https://gist.githubusercontent.com/staaldraad", "Script3",
    "Unknown"
)
| where DetectedScript != "Unknown"
| project Timestamp, DeviceName, DeviceId, AccountName, InitiatingProcessCommandLine, DetectedScript, ReportId
```
