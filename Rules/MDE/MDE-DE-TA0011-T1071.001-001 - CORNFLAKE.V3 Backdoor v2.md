### 2. DETECTION OVERVIEW

**Description:**

- This detection identifies suspicious activity where Node.js processes initiate connections to public IPs and remote URLs matching a specific regex pattern. This behaviour may indicate the presence of the Cornflake v3 backdoor or similar malicious activity.

**Hypothesis:**

We hypothesise that an adversary using the Cornflake v3 backdoor will execute a Node.js process that connects to public IPs and remote URLs with a specific structure (e.g., `api^[a-zA-Z0-9]{18}.com`). This activity can be observed through process execution and network connection logs.

- **Tactic(s):** Command and Control (TA0011)
- **Technique(s):** Application Layer Protocol (T1071)

### 4. LOGIC & IMPLEMENTATION

**Detection Logic (Pseudocode or SIEM Query):**

-- Provide the query here.  
-- Comment heavily to explain each logical step of the query.

```
DeviceNetworkEvents
| where InitiatingProcessFileName contains "node.exe" // Focus on Node.js processes
| where RemoteUrl matches regex @"^api\.[a-zA-Z0-9]{18}\.com$" // Match specific URL pattern
| where RemoteIPType == "Public" // Ensure the connection is to a public IP
| project Timestamp, DeviceName, DeviceId, RemoteIP, RemotePort, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountDomain, InitiatingProcessFileSize, RemoteUrl, AdditionalFields, ReportId
```

**Known False Positives:**

- Nil

**Exclusion Strategy:**

- Exclude processes signed by trusted vendors.
- Exclude chrome processes and only focus on node.exe
- Exclude activity on domain controllers.
