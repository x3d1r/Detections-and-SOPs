### **2. DETECTION OVERVIEW**

**Description:**

This analytic detects unusual or potentially unauthorized certificate requests, approvals, or resubmissions. Abnormal usage of certificates can be an indicator of adversaries attempting to impersonate users or establish persistence through trusted mechanisms like Active Directory

**Hypothesis:**

We hypothesize that an adversary performing **Subvert Trust Controls (T1553.004)** will attempt to request or resubmit a certificate using Active Directory Certificate Services. This activity can be observed through **Windows Security Event IDs 4886 and 4887**, and **System Event ID 39**—events which indicate certificate operations that can be anomalous when conducted by unexpected users or outside business norms.

### **4. LOGIC & IMPLEMENTATION**

**Detection Logic (Pseudocode or SIEM Query):**

Detection Logic - YARA-L

```sql
rule abnormal_certificate_requests
{
  meta:
    id = "DE-TA0004-T1553.004-001"
    title = "Abnormal Certificate Request Detection"
    description = "Detects unusual certificate request, approval, or resubmission activity using Windows Event IDs 4886, 4887, and 39."
    version = "1.0"
    author = "Lucian Peckham"
    date_created = "2025-09-25"
    tactic = "Defense Evasion"
    technique = "T1553.004"
    platform = "Windows"
    status = "test"

  events:
    $cert_request = {
      udm.event_type = "SECURITY_EVENT",
      udm.event.security_event.id == 4886
    }

    $cert_approval = {
      udm.event_type = "SECURITY_EVENT",
      udm.event.security_event.id == 4887
    }

    $cert_resubmit = {
      udm.event_type = "SYSTEM_EVENT",
      udm.event.system_event.id == 39
    }

  condition:
    any of ($cert_request, $cert_approval, $cert_resubmit) within 1h
}
```

**Known False Positives:**

- Legitimate internal PKI operations during maintenance.
- Automated certificate requests by security software or endpoint management platforms.
- Developer test environments generating certificates for automation.

**Exclusion Strategy:**

- Exclude known PKI service accounts with certificate-related roles.
- Exclude certificate requests from known system management tools with trusted signatures and paths.
- Filter requests by time-of-day or frequency thresholds to catch abnormal spikes.
