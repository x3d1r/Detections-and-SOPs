### **2. DETECTION OVERVIEW**

**Description:**

This analytic detects when a user account creates more than a typical number of scheduled tasks (via Event ID 4698 or 106) within 24 hours. Excessive task creation is often associated with persistence techniques used by adversaries, malware, or script-based automation.

**Hypothesis:**

We hypothesize that an adversary performing **Scheduled Task/Job (T1053.005)** for **persistence** or **execution** will create tasks using native Windows Task Scheduler interfaces, generating observable events such as 4698 (Security Log) or 106 (Task Scheduler Operational Log).

### **4. LOGIC & IMPLEMENTATION**

**Detection Logic (Pseudocode or SIEM Query):**

### **Detection Logic (YARA-L for Chronicle):**

```sql
rule unusual_scheduled_task_creation
{
  meta:
    id = "DE-TA0003-T1053.005-001"
    title = "Detection of Unusual Scheduled Task Creation"
    description = "Detects rare or suspicious scheduled task creation using Windows Event ID 4698 and 106."
    version = "1.0"
    author = "Lucian Peckham"
    date_created = "2025-09-25"
    tactic = "Persistence"
    technique = "T1053.005"
    platform = "Windows"
    status = "test"

  events:
    $security_event = {
      udm.event_type = "SECURITY_EVENT",
      udm.event.security_event.id == 4698
    }

    $scheduler_event = {
      udm.event_type = "TASK_SCHEDULER_EVENT",
      udm.event.task_scheduler_event.id == 106
    }

  condition:
    // Detect users creating more than 3 scheduled tasks within 24 hours (can tune)
    (
      $security_event in last(24h) by $security_event.principal.user.userid
      and count($security_event) > 3
    )
    or
    (
      $scheduler_event in last(24h) by $scheduler_event.principal.user.userid
      and count($scheduler_event) > 3
    )
}
```

### **Known False Positives:**

- Software deployment tools (e.g., SCCM, Tanium, PDQ Deploy)
- Scripts from IT operations or patch management systems
- Antivirus or EDR agents creating scheduled tasks for scans or updates

### **Exclusion Strategy:**

- Allowlist known service accounts (e.g., `svc_deployment`, `svc_patch`)
- Exclude tasks created by trusted applications (`udm.src.program_name`)
- Monitor creation time (e.g., allow scheduled tasks during change windows)
